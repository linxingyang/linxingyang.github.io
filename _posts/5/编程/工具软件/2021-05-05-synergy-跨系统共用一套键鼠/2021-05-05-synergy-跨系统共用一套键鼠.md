MouseWithoutBorder可以在两台windows之间共用一套键鼠，而synergy则是可以跨系统共用一套键鼠，牛批PLUS。

# 安装

## ubuntu

ubuntu 20安装：
```shell
# apt-get install -y libqt4-network libqtcore4 libqtgui4 synergy
```

## windows

在[官网中](https://sourceforge.net/projects/synergy-stable-builds/)的[下载路径](https://sourceforge.net/projects/synergy-stable-builds/files/v1.8.8-stable/synergy-v1.8.8-stable-Windows-x86.msi/download)，windows直接安装就可以了。

# 配置

ubuntu或者windows都可以作为服务器，此处windows作为服务器，ubuntu作为客户端。
